## About

I'm a software and digital product builder based in Brazil. I'm interested in how software can simplify business operations, make information easier to work with, and turn complex workflows into useful products.

My work brings together product planning, application development, interface design and technical documentation. I care about the decisions behind a product as much as the interface people use.

## How I work

I start with the problem, define the scope, and build in stages. I prefer documenting important decisions, validating assumptions early, and making improvements that can be tested rather than relying on feature lists alone.
